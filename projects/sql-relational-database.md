# SQL Relational Database Portfolio

## Overview

Practice schemas and queries designed to show relational thinking, data integrity, and safe database operations.

## What I practiced

- Normalized table design
- Primary and foreign keys
- Required and unique constraints
- Joins across related entities
- Inserts that let the database generate IDs
- Updates and deletes with targeted conditions
- Parameterized queries
- Persistence after closing and reopening SQLite
- Duplicate rejection and missing-related-record handling

## Tools

`SQL` · `SQLite` · `relational modeling` · `joins` · `constraints` · `parameterized queries`
