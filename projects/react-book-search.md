# React Book Search

## Overview

A React search interface connected to the Open Library API.

## What I built

- Controlled search inputs
- Multiple query branches
- API request and response handling
- Loading, success, empty, and error states
- Result rendering with reusable UI components
- Input and navigation checks across responsive layouts

## What it demonstrates

This project shows how I handle asynchronous data, user input, API failures, and the difference between a successful request with no results and a failed request.

## Tools

`React` · `Vite` · `JavaScript` · `REST API` · `JSON` · `CSS`
