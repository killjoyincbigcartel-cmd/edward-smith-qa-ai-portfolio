# AI Resume Helper & Web Automation

## Overview

A Python-based prototype for resume assistance and browser automation. The project connects practical career tooling with repeatable validation of dynamic web content.

## What I practiced

- Translating user input into structured resume-support output
- Navigating dynamic pages with Playwright
- Collecting records from a changing page state
- Verifying that 100 records were returned in the expected order
- Separating data collection, validation, and reporting steps
- Documenting assumptions and repeatable checks

## Engineering and QA value

The project demonstrates how I approach automation: define the expected result first, collect data, validate the result, and report a failure clearly enough to investigate.

`Python` · `Playwright` · `browser automation` · `data validation` · `technical documentation`
