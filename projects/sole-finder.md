# SOLE//FINDER — Sneaker Discovery PWA

## Overview

A responsive React and Vite product-discovery application for browsing sneaker brands, models, collections, and purchase links.

## Features

- Search and browse experiences
- Brand, model, player, and collection categories
- Favorites and trending sections
- Filters and dropdown navigation
- Separate shoe and apparel organization
- Responsive portrait and landscape layouts
- External purchase links
- Installable progressive-web-app behavior

## QA focus

I tested image reliability, search behavior, filters, navigation, favorites, external links, responsive layouts, and the difference between authenticated and public states.

## Tools

`React` · `Vite` · `JavaScript` · `HTML/CSS` · `responsive testing` · `browser QA` · `PWA`
