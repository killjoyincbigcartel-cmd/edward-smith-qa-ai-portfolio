# Resume-Ready Project Bullets

Use the bullets that match the role. Do not list a project as deployed or production-ready unless the public link and evidence support that claim.

## QA-focused bullets

- Created functional, regression, smoke, exploratory, responsive, and API test cases for e-commerce, registration, and web-application workflows.
- Documented Jira-style defects with reproducible steps, expected versus actual results, severity, priority, environment details, and retest notes.
- Built a Python/Flask Movies REST API and validated CRUD operations, JSON responses, persistence, duplicate records, invalid input, not-found behavior, and SQL-safety controls.
- Used Playwright to automate browser workflows and verify dynamic content ordering across 100 records.

## Software-focused bullets

- Built responsive React/Vite applications using controlled forms, public APIs, reusable components, loading states, empty states, and error handling.
- Designed SQLite schemas with primary keys, foreign keys, constraints, joins, parameterized queries, and persistence checks.
- Built and QA-tested SaaS and e-commerce workflows involving authentication, dashboards, uploads, checkout, analytics, and notifications.

## AI-focused bullets

- Built an AI-assisted resume-tool prototype and separated input handling, automation, output validation, and documentation into repeatable workflow steps.
- Designed a human-approved AI inquiry-triage workflow with account isolation, audit logging, failure handling, output evaluation, and privacy controls.
