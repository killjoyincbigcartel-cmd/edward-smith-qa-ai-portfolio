# AI Software Engineering Direction

My goal is to build AI-enabled software that is useful, testable, secure, and deployable—not only a prompt demo.

## Skills I am developing

- Python application and API development
- REST and JSON integrations
- SQL data modeling and persistence
- Authentication and authorization
- AI API and model integration
- Retrieval-augmented generation and knowledge grounding
- Agent/tool workflows with human approval
- Prompt and model-output evaluation
- Automated tests for normal, failure, safety, and edge cases
- Logging, rate limits, cost awareness, and deployment

## Evidence already in the portfolio

- [Movies REST API](../projects/movies-rest-api.md) shows API, database, validation, and testing foundations.
- [AI Resume Helper](../projects/ai-resume-helper.md) shows practical automation and result validation.
- [WE Recover](../projects/we-recover.md) shows product workflows, account boundaries, analytics, and notification design.
- [SOLE//FINDER](../projects/sole-finder.md) and [React Book Search](../projects/react-book-search.md) show front-end and API integration work.

## Recommended certification direction

The current beginner Microsoft AI certification is **AI-901 Azure AI Fundamentals**. The later **AI-103 Azure AI Apps and Agents Developer Associate** is more aligned with building and deploying Python-based AI applications, but it should come after stronger hands-on Azure and AI project experience.

## What I want each AI project to show

1. The user problem and success criteria.
2. The application architecture and data flow.
3. The AI feature and why it is appropriate.
4. How output quality, safety, and failure cases are evaluated.
5. How authentication, privacy, cost, and rate limits are handled.
6. How the project is tested and deployed.
